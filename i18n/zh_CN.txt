# PuTTY 简体中文界面翻译
#
# 使用方法：把本文件复制到 putty.exe 所在目录，并命名为
#     putty-i18n-zh_CN.txt
# 程序启动时会按系统界面语言自动查找对应文件；也可以用环境变量
#     PUTTY_LANG=zh_CN
# 强制指定。找不到文件时界面保持英文，不会出错。
#
# 格式：英文原文=译文
#   * 以 # 开头的行是注释，空行忽略；
#   * 英文原文必须与程序中的字符串完全一致（包括 & 加速键标记和末尾的冒号）；
#   * 两侧的空格会被去掉；
#   * 支持 \n \r \t \\ 转义；
#   * 想修改某个用语，改右侧内容后重启程序即可，无需重新编译；
#   * 增加其它语言只需复制本文件为 putty-i18n-<语言>.txt 再翻译。
